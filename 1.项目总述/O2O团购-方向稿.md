## 1. 一句话

在 App 里新开一条**宠物本地服务团购**业务线：线下团队签约大雅加达的宠物门店，用户在 App 里预付买券，到店核销；平台代收货款、核销后给商家结算，按**佣金**抽成。

## 2. 为什么现在做

| 目的 | 说明 |
|---|---|
| **变现** | 公司目标转向变现，需要一条从第一天就有收入的业务线。团购是预付模式，每一笔核销都直接产生佣金 |
| **新获客渠道** | 每家合作门店都是拉新入口：店内物料上的码、门店发给自家 WhatsApp 客户的团购链接，都要求用户下载 App 才能买 |
| **线下资产打通（换一种方式）** | 自家门店（用 PAWSI）当普通商家之一，用户买券、到店核销即可。不需要 PAWSI 开放接口，也不需要 PawCoin 在线下消费，9-28《线上线下会员打通》里的两个阻塞点在本模式下都绕开了 |

## 3. 已拍板（2026-11-26）

| 项 | 结论 |
|---|---|
| 模式 | 美团式团购：预付买券 → 到店核销 → 平台结算给商家 |
| 资金 | **平台代收，分账结算**，优先用支付网关的分账 / 子账户，平台账上不沉淀商家的钱（须法务确认，见 §9） |
| 收入 | **佣金抽成**：售价由商家定，平台按比例抽佣 |
| 佣金比例 | **6–7%，线下团队在区间内逐家谈**。后台设全局默认值 + 按商家覆盖（同 1.4.1 返佣比例的两层做法） |
| 免佣期 | 不统一给；**线下团队视情况给**，后台能按商家设免佣期（期内核销不扣佣金，支付手续费照收） |
| 支付手续费 | QRIS / 网关分账费**单列向商家收**（同 Grab），不含在佣金里 |
| 退款 | 未核销**随时可退，用户自己发起，不用审核**；**运营通过 GemPay 人工退到用户填写的银行或电子钱包账户**（不是自动到账，要写明到账时限，可参照电商退款「最多 3 个工作日」），**每一笔都扣转账手续费（包括 BCA）**，金额按 GemPay 费率，在购买页和退款确认框写清楚。宣传说「随时可退」，不说「全额退」 |
| 结算打款 | **批量结算：前期每 3 天一次，单量起来后改按周或按月**（合同写「结算周期由平台通知调整」）：后台按核销算好每个商家的应结金额，运营照数通过 GemPay **人工打款**到商家的银行或电子钱包账户（渠道是通的，但不是自动打款），转账手续费由商家承担（含在「支付手续费单列」里）。打款后在后台登记，可复用 1.4.1 商家平台的「打款登记」 |
| 有效期与过期 | 默认 **90 天**（运营可按单张团购改）。**过期不自动退**：过期前第 10、5、3、1 天和当天各提醒一次，用户可主动退；不退则过期作废。**作废的钱归谁：等法务意见再定**（§9 第 6 条） |
| 预约 | **平台内预约，分两步**（2026-11-26 定）。**第一版「预约申请」**：用户选 2–3 个期望时间（寄养选入住和离店日期），商家在商家端确认其中一个或改约；可以先买券以后再约，也可以在详情页选时间并直接付款。**二期「实时空档」**：店铺页公开展示空闲时间，用户自助选择 |
| 约不上 | 商家提出新时间；用户不接受可**全额退款、不扣手续费**（责任在商家）。商家超时没处理，提醒商家和运营（时限写 PRD 时定） |
| 商家端预约管理 | **第一版**：预约日历（平台预约 + 商家**手动录入的线下预约**，WhatsApp、到店散客都录进来），确认 / 改约。**二期**：员工排班、按服务时长占位，做成完整的预约管理工具，与实时空档一起上。目标是商家所有预约都在我们这里管，空档才是真的 |
| 预约后退款 | 预约确认后，**预约时间前 X 小时内系统拦截退款**。X 按品类：**寄养 48 小时 · 摄影 24 小时 · 洗护、疫苗 / 体检 12 小时**，运营可按单张团购改。用户爽约怎么处理（券是否作废、能否改约）写 PRD 时定 |
| 增值税 | 平台目前**非 PKP**，佣金账单不收增值税。合同写「佣金不含增值税；若平台依法成为增值税纳税人，按规定另行加收」。年营业额超 Rp 4,8 miliar 须登记 PKP，团购是否只按佣金计营业额要税务顾问确认（§9 第 2 条） |
| 价格保护 | 线下团队和商家谈的「平台最低价」写成合同里的**价格保护条款**：商家保证在其他渠道不卖得比本平台便宜。它不是底价 |
| 品类与上线顺序 | **洗护美容 → 寄养 → 宠物摄影 → 疫苗 / 体检**（2026-11-26 按调研调整）。洗护美容首发，后面的品类按顺序签约、上架；商品模型一次支持到位 |
| 后续品类池 | 宠物友好餐厅 / 咖啡（Grab、Gojek 已在做餐饮券，不是主战场）· 训练师（原 Roadmap 2.3.0） |
| 首发区域 | 整个大雅加达，不限片区 |
| 商家入驻 | 线下团队负责谈价并**代商家注册**；第一版不做商家自助入驻 |
| PawCoin 买券 | **系统预留开关，法务同意后打开**（法务需求 A 组第 4 条）。风险：撮合模式下 PawCoin 实际付给第三方商家（含 DNA），可能动摇「封闭式、仅限 App 内消费」的定性 |
| 退成 PawCoin | 退款时用户可选**退成 PawCoin：免手续费、即时到账**（钱不流向商家，不受上条限制）；或退到银行 / 电子钱包（扣手续费、人工约 3 个工作日） |
| 主入口 | **Sosial 顶部「入口配置区」**：一行图标，运营在后台配置（团购、话题、「逛别人家的毛孩子」宠物推荐、活动等），点击进入对应页面。放在信息流最上面、**跟着信息流滚走、不吸顶**，「Jelajah（发现）」和「Mengikuti（关注）」两个 Tab 都放。首发期团购固定第一位 |
| 配置区归属 | 配置区是通用功能，**单独一份 PRD、先于团购上线**（先放话题、宠物推荐）；团购上线时只是在后台加一个图标 |
| 其他入口 | Toko 首页放一个团购入口块（接住带购买意图的用户）· 提醒里带团购（洗护周期、疫苗、生日 / 纪念日）· 宠物档案 / Diary 里 · 社区帖子挂团购卡片 · 运营位（弹窗、站内信、banner 可跳团购） |

## 4. 三条流程

**用户**

```
发现团购（App 入口 / 门店码 / WhatsApp 分享链接 → 网页落地页 → 下载 App）
  → 详情页 → 支付（QRIS / 电子钱包）→「我的券」（券码 + 二维码）
  → 需预约的券：在 App 里选期望时间 → 商家确认或改约（也可以在详情页选好时间直接付款）
  → 到店出示 → 店员核销 → 服务记录写进宠物成长档案
```

**商家**

```
线下团队谈价、代注册 → 运营在后台上架团购（审核把关）
  → 店员扫码 / 输码核销 → 看核销记录和结算账单 → 收到结算款
```

**资金**

```
用户付款 → 平台代收（分账账户）
  → 核销后进入「待结算」→ 每 3 天（量大后按周 / 月），后台汇总每个商家的应结金额（扣佣金和手续费）→ 运营通过 GemPay 人工打款并在后台登记
  → 未核销的券由用户主动退款，运营通过 GemPay 人工退到用户账户（扣转账手续费）；过期未退的券作废，钱的归属待法务意见
```

## 5. MVP 边界

**做**

- 用户端：团购入口与列表（按品类、距离筛选）· 详情页 · 购买 · 我的券 · 退款 · 网页落地页（用于分享）
- 商品模型**所有品类共用一套「套餐券」**：如中型犬洗澡加剪指甲、寄养 1 晚、影棚 1 小时加 10 张精修、猫三联疫苗
  - 每张券有「需提前预约」开关（寄养、摄影、疫苗打开，洗护按门店习惯），打开后走平台预约申请
  - 代金券（花 80k 当 100k 用）原本是给餐饮准备的，随餐饮一起延后
- 商家端：复用 1.4.1 商家平台，新增核销、核销记录、结算账单
- 运营后台：商家与门店资料、团购创建与上下架、退款处理、结算
- 获客归因：用户买券或在门店扫码时，记录是从哪家店来的

**不做（第一版）**

- 实时空档展示与用户自助选时间（二期）· 员工排班、按服务时长自动占位（二期）
- 商家自助创建或编辑团购
- 用户评价与评分（另行排期；第一版可以先只收集不公开）
- 上门服务
- 积分抵扣（PawCoin 买券做成开关，法务同意后打开）

## 7. 差异化：服务进成长档案

光做团购，我们和本地优惠平台没有区别，用户也可以直接打 WhatsApp 找门店。我们独有的是宠物档案：

- 券核销后，在该宠物的 Diary 自动生成一条服务记录，比如「Mochi 今天洗了澡」，用户可以补照片
- 摄影券核销后，成片直接进 Diary，可以做 KTP 照片、里程碑分享图，也可以一键发到社区；生日、陪伴纪念日推送时推荐拍摄套餐
- 疫苗券核销后写进健康记录，接上 1.5.0 的疫苗提醒
- 洗护记录满一个周期（比如 30 天）后提醒「该洗澡了」，并附上上次那家店的团购，形成复购闭环

这部分也可以当作第二步，MVP 先保证买券和核销跑通。

## 8. 指标（给老板 / 融资看的数）

| 指标 | 证明什么 |
|---|---|
| 签约商家数、上架团购数 | 供给能起来 |
| 交易额、平台佣金收入 | 收入线成立 |
| 核销率（已核销 / 已售出） | 券是真实消费，不是囤券 |
| **通过商家渠道新注册的用户数** | 「新获客渠道」成立 |
| 买过的用户 30 天内再次购买的比例 | 不是一次性薅羊毛 |
| 退款率 | 商品和门店质量 |

## 9. 法务与合规：上线硬门槛，现在就启动

不依赖 PRD，可以并行：

1. **代收代付**：平台收钱后结给第三方商家，需要什么许可？Bank Indonesia 新的支付系统条例（PBI 10/2025）已于 2026-03-31 生效，公开资料里查不到「平台代收再结算」是否需要自己持支付服务商牌照。行业通行做法是接持牌网关的分账 / 子账户，例如 Xendit xenPlatform：每个商家一个子账户，核销后分账，平台按笔扣佣金。要请律师和网关**书面确认**三件事：
   - 核销前钱挂在哪个账户、法律上属于谁
   - 商家子账户要哪些认证材料。线下团队代注册时要一并收齐，可能包括店主身份证（KTP）、税号（NPWP）、营业执照号（NIB）、银行账户
   - 结算是 T+几
   - 备注：Midtrans 只查到代付功能，钱会在我们名下过一手；Stripe 印尼不支持这种场景
2. **佣金模式的税务**：
   - 按现行规定，代金券本身不征增值税，只对平台的佣金征。但我们适用哪种口径要税务顾问确认：「代金券营销服务」有特定比例的计税办法（PMK 71/2022），还是按普通平台服务费计税
   - 交易额起来后是否触发增值税纳税人（PKP）登记。官网项目定的是「自营非 PKP」，团购会改变这个前提
   - 系统要预留按商家代扣所得税的字段：平台代扣卖家 0.5% 所得税的规定（PMK 37/2025）一再推迟，代收规模大了可能会被指定为代扣方
3. **商家合同模板**：佣金比例、结算周期、价格保护条款、退款责任划分、服务出问题（尤其寄养和疫苗）时的责任归属
4. **疫苗 / 体检**：由合作诊所提供并对医疗服务负责，平台只是售券渠道，页面上的说明怎么写
5. **用户条款**：新增团购与退款规则；PawCoin 买券是否可行（见法务需求 A 组第 4 条）
6. **过期作废**：预付了但服务没发生、过期不退款，是否符合印尼消费者保护法（UU 8/1999）；要多显著地告知（购买页、券页、提醒）；作废的钱归商家还是平台、怎么入账、要不要缴税
7. **退款扣手续费**：可以向用户收多少，要在条款里怎么写
8. **SIUPMSE 与经营范围**（2026-11-26 补）：官网的 SIUPMSE 正在审核，申报的是「B2C 自营、没有第三方商家」；团购后变成替第三方销售，可能要变更申报、给 NIB 加经营范围代码，并决定在审核通过前还是之后提
9. **支付服务商**：现有 QRIS 走 **GemPay，已确认支持分账**（2026-11-26），不用另接网关。还要和 GemPay 确认：分账费率、核销前资金挂在哪个账户、商家子账户要哪些资料（线下团队代注册时一并收齐）、结算 T+几、能否按商家设不同佣金

**格局：宠物服务团购在印尼是空白**

- 独立团购平台在印尼没有活下来的：Fave（前身是 Groupon Indonesia）2023-04 退出。现在还在做的，都是超级 App 或旅游平台里顺带的一个功能，只做餐饮或景点：Grab Dine Out、Gojek GoDineIn、ShopeeFood、Traveloka Xperience、tiket.com To Do
- 印尼的宠物服务平台（Petskita、PETO 等）全是预约制或按次付费，规模都很小，**没有一家卖预付券**
- 对我们的意义：「独立团购 App + 补贴拉新」在印尼有失败先例。活下来的做法都是**挂在已有的高频场景上**。我们有社区和成长档案，正好属于这一类

**可以直接借鉴的做法**

| 项 | 参照 | 对我们的建议 |
|---|---|---|
| 结算 | Grab Dine Out：核销后**不超过 3 个工作日**打款，费用含税；美团：按核销结算、周结 | 按核销结算，商家后台能看到每一笔。**已定前期每 3 天批量人工打款，量大后改按周 / 月**（2026-11-26）；对小商家是卖点 |
| 退款 | 美团：随时退、过期自动退；印尼竞品大多按商家政策，甚至不可退 | 随时退 + 过期自动退，这本身就是差异点；但寄养、美容这类占档期的服务，**约好时间后加一个不可退的锁定期**。自动退款要做到账核对 |
| 核销 | 美团、Grab、GoDineIn 都是扫码或输码 | 商家用网页端扫码或输码，支持一单多券、误核销可以短时间内撤销；不做商家 App |
| 佣金 | 各家都不公开；Grab 对新商家有试用佣金和补贴 | 先定统一的低佣金，加首月免佣；报价写明含不含增值税 |
| 宠物医疗 | 美团宠物把常见诊疗做成标准化套餐，宠物团购交易额同比增长 76%（2026-08） | 疫苗 / 体检只上标准化套餐，并单独审核诊所和兽医资质 |
| 核销率 | 美团 80–90%，抖音约 50%（冲动购买） | 核销率是判断是否真实需求的关键指标（已列在 §8） |

**调研对品类顺序的建议（已采纳，见 §3）**

先洗护美容，再寄养，疫苗 / 体检晚一点；餐饮不是主战场（Grab、Gojek 已经在做）。宠物摄影在调研范围外，2026-11-26 讨论加入，排在寄养之后。

## 11. 待定项（写 PRD 时定）

- 社区帖子挂团购卡片：谁能挂（用户自己选 / 核销后自动带）、卡片样式
- 是否限每人购买数量
- 过期作废的钱归商家还是平台（等法务意见）
- 过期提醒走推送还是站内信，用户关了推送怎么办（1.4.0 起有推送分类开关）
- 宠物摄影的供给形态：影棚（有门店）和户外跟拍摄影师（无门店、个人）怎么入驻、怎么核销
- 佣金的监管变量：中小微企业部（2026-01）在研究平台对中小商家收费的上限，佣金不宜定太高
- 寄养这类大额券要不要拆成「定金 + 到店付尾款」
- 从门店来的用户是否自动绑定该门店的邀请码（已绑定其他门店的怎么处理）
- 商家端核销是用网页，还是另做轻量的店员端
- 首批商家数量目标、线下团队签约节奏（建议首发前洗护美容先签 20–30 家；寄养、摄影、疫苗按顺序跟上）

## 12. 决策日志

| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-11-26 | O2O 从「到店预约 + 线下付款」（原 Roadmap 2.0.0）改为**预付团购** | 目标转向变现；预约模式第一版不收钱，商家侧还要做排期、调度 |
| 2026-11-26 | 收入用**佣金抽成**，不做底价差价 | 差价模式下平台更像销售方，税务和发票更重；「平台最低价」改为价格保护条款 |
| 2026-11-26 | 商家由**线下团队代注册**，团购由运营上架 | 赶时间，并保证首批团购的质量；商家自助等跑出数据再开放 |
| 2026-11-26 | 品类顺序改为**洗护美容 → 寄养 → 宠物摄影 → 疫苗 / 体检**，宠物友好餐饮移入后续品类池 | 竞品调研：洗护标准化、复购高最易冷启动；疫苗要标准化套餐和资质审核；餐饮券 Grab、Gojek 已在做。摄影能把成片放进成长档案，差异最大，原 Roadmap 2.3.0 预约制摄影并入团购 |
| 2026-11-26 | 主入口放 **Sosial 顶部入口配置区**，不新增底部 Tab，也不在 Toko 顶部分「商品 / 服务」两栏 | 底栏 5 个位置已满；社区带团购（大众点评、小红书式）和「帖子挂团购」一个逻辑，游客也落在社区，利于拉新；配置区还能放话题、宠物推荐。代价：配置区会把信息流往下推，打破 1.5.4 搜索定的「信息流位置不变」，所以跟流滚走、只占一行；社区用户偏冲动购买，要盯核销率 |
| 2026-11-26 | 佣金 **6–7% 逐家谈**、免佣期线下团队视情况给、支付手续费单列向商家收 | 竞品不公开费率，美团示例 5%；中小微企业部在研究平台收费上限，不宜高；手续费单列对标 Grab，平台佣金不被手续费吃掉 |
| 2026-11-26 | 退款：未核销随时退、扣转账手续费；有效期默认 90 天；**过期不自动退**，过期前第 10 / 5 / 3 / 1 天和当天提醒，不退即作废；需预约的券只做「预约前 X 小时不能退」提示（寄养 48 / 摄影 24 / 洗护、疫苗 12 小时），系统不拦 | 自动退要由平台承担转账手续费；改为多次提醒、用户自己决定。预约状态系统不知道，第一版不做拦截 |
| 2026-11-26 | **预约改为平台内做**，替代 WhatsApp 约时间：第一版「预约申请」（用户选期望时间、商家确认或改约，商家端能录线下预约），二期「实时空档」公开展示、自助选择、完整预约管理工具；先买券后约、选时间直接付款两种都支持；商家约不上、用户不接受时全额退；预约确认后 X 小时内系统拦截退款 | 平台要有预约记录、帮商家排时间、让用户看到空档。分两步是为了不拖慢首发；商家线下单也要录进来，否则空档不准。退款锁定期因此可以真正执行 |
| 2026-11-26 | 结算款和退款都由**运营通过 GemPay 人工打款**（GemPay 能打到银行和电子钱包，但不自动），**每笔都收手续费**（包括 BCA） | 第一版不做自动打款；团购退款不沿用电商「BCA 免手续费」的口径 |
| 2026-11-26 | 结算**前期每 3 天批量一次，量大后改按周 / 月**，后台算好应结金额，运营照数人工打款 | 前期单量少，人工负担不大；后台已能出应结数额，只需人员操作 |
| 2026-11-26 | PawCoin 买券**系统预留开关、法务同意后打开**（法务需求提到 A 组）；退款可选**退成 PawCoin**（免手续费、即时） | 想第一版就支持，但撮合模式下可能动摇 PawCoin 的封闭式定性，由法务定；退成 PawCoin 不涉及付给商家，可直接做，还能减少人工打款、让钱留在 App 里 |
