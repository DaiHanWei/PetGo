◇ 概念

白纸上的小动物。页面以白为主，每屏最多一块饱和主色形状（圆 / 胶囊 / 软方块 / 圆角块），一只真实宠物照片整只站在形状上沿；好玩靠宠物照片、形状和交互动效，不靠颜色轰炸。落地页（首页、关于、商城首页、购物指南、404、小测）用主形状 + 照片；内页（商品详情、购物车、结算、付款、订单、账户、工单、登录）以效率为主，最多一个小色块或一张小照片。

◇ 动效（只在原型和上线代码里；静态稿每屏都是最终可见状态）

  • 默认可见：CSS 默认值就是最终可见状态，动画只能「从某个状态播到可见」；进站 2.5 秒后仍停在起点的动画直接跳到终点；当前站判定除 IntersectionObserver 外，再按位置每秒校一次。
  • 只动 transform / opacity / clip-path；切屏用浏览器原生 scroll-snap，不拦截滚轮和触摸。
  • 跨站角色：每站换姿势照片、每站不同的进场方式（掉落 / 抛物线跳 / 滑入 / 从形状里弹出 / 转身换姿势 / 无力落下 / 连弹），落地挤压回弹，落地后道具动作；主形状在圆 / 胶囊 / 软方块间 clip-path 变形 + 两层交叉换色（720ms）；首屏 15 只依次掉落弹起；停留 2 秒后才有空闲动作（呼吸 / 歪头），每 4–6 秒最多一次，不循环。
  • 点击反馈：按钮按下缩到 0.96；宠物、物种、加购按钮挤压回弹（约 440ms）。
  • 系统「减少动态效果」或页面开关打开：全部动效关闭、不吸附，内容照常。

◇ 禁止项

不标站号（不写「05 / 08」「/365」这类序号）；不做半截元素（只管照片和装饰元素：不裁切、不出血、不「从后面探头」；抽屉 / 列表里正常滚动露出的一截内容不受限，抽屉高度照 App 代码）；不描边加硬投影；不铺满整屏颜色；不用颗粒纹理或半透明叠色；框内不用 emoji；不用表外颜色和表外字号。

规范页（框外说明）：这一屏是规范容器，不是网页；上面的组件是真实渲染（d-style.css）。颜色都能在 App colors.dart 找到出处，字号以本表为准。和 App 不同的地方（网站自己的视觉）：按钮全圆角、主按钮用 logo 紫 #7D45F6（App 主色是 #845EC9）、商品价格墨色（App 紫色）、正文 16（App 15）、展示字体 Bricolage（App 只有 Poppins）、车票券和主形状 App 没有——App 是否跟进另行决定，本版 App 不改。
