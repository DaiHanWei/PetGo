替代 A1。Paket Hemat 在售时还是一行等分，每格约 82 宽，字号不缩（标题 13、副标 11）。内容顶部对齐：四个图标在同一高度，标题从同一高度开始。实测（Poppins）每格可用约 76：Pesanan / Riwayat / Koin 一行放得下；Paket Hemat（85）放不下，折 2 行；副标 Lacak pesanan、50rb · 17 jatah、Hemat Rp10.000 也会折 2 行（不截断）。数字和单位不拆开：「17」和「jatah」之间用不断行空格（\u00A0），断成「50rb · / 17 jatah」。Paket Hemat 永远在最后，上下架时前 3 格位置不动（符合 PRD FR-275）。卡高 112，和 A1 一样。

Replaces A1. While Paket Hemat is on sale it is still one equal-width row; each cell is about 82 wide, at full size (title 13, sub 11). Top-aligned: all four icons sit at the same height and titles start on the same line. Measured (Poppins), about 76 is usable per cell: Pesanan / Riwayat / Koin fit on one line; Paket Hemat (85) doesn't and wraps to 2 lines; the subs Lacak pesanan, 50rb · 17 jatah and Hemat Rp10.000 also wrap to 2 lines (no cut-off). Keep number and unit together: a non-breaking space (\u00A0) between "17" and "jatah", so it breaks as "50rb · / 17 jatah". Paket Hemat always stays last, so the first 3 cells never move when it comes and goes (as PRD FR-275 says). The card is 112 tall, the same as A1.
