Kamu tidak akan melihat konten ini lagi

由 D1「Laporkan」→ 原有举报抽屉（选理由 → 提交 → 成功态，都不改）。关掉成功态后，和 Sosial 一样（openReport 的 onReported）：被举报的帖子（Dinda）立刻从列表移除，后面的卡按同一规则重新排（Bimo 从右列移到左列），两列都一直排到屏幕下方，底部出现 Sosial 同一条提示 reportHiddenToast「Kamu tidak akan melihat konten ini lagi」（Material 默认 SnackBar）。之后服务端也会把它隐藏（PRD FR-279），刷新也不会再出现。取消举报表单什么都不变。

From D1, "Laporkan" → the existing report sheet (pick a reason → submit → success state, all unchanged). Once the success state is closed, it works as in Sosial (openReport's onReported): the reported post (Dinda's) is removed from the list at once, the cards after it re-flow by the same rule (Bimo moves from the right column to the left) with both columns running on past the bottom of the screen, and Sosial's message reportHiddenToast "Kamu tidak akan melihat konten ini lagi" shows at the bottom (default Material SnackBar). The server hides it from then on (PRD FR-279), so a refresh doesn't bring it back. Cancelling the report form changes nothing.
