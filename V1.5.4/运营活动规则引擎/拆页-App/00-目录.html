本稿内容

  • A 到账与获奖通知：两类新通知（A1 到账、A2 获奖、A3 获奖推送），A4 奖励项多时正文展开，A5 没有免费次数但含头像框时的正文与落点。
  • B 奖励去向：B1「Koin & Jatah Saya」免费礼物按档（Rp1.000 / 5.000 / 10.000）显示与次数记录；B2 送礼包装页按礼物单价用对应档的免费次数。
  • G 活动发的头像框：G1 等级页头像框一排（限时普通款 / 永久活动专属款「Khusus event」/ 永久普通款）；G2 永久活动专属框抽屉（没有「Beli lagi」）；G3 / G4 活动专属框快到期推送与通知中心。
  • P 虚拟商品付款：头像框、KTP 高清（含护照快照、登机牌）、超值礼包、性格测试、多宠物名额都有 QRIS 原价 + PawCoin 优惠价，付款抽屉 PawCoin 卡加右上角「推荐」点赞小圆标（PRD §3.11）——P1 / P2 头像框（默认 / 余额不够）、P3 KTP 高清、P4 超值礼包、P5 性格测试补差价、P6 多宠物名额。
  • 示例框：Dreamy Cat、Peachy Puppy 是线上现有两款（图取线上）；Kembang Api（烟花）是示例用的活动专属款，框图为示意。

研发执行说明

给研发的 AI：先读这里，再按 拆页-App/ 逐屏实现；屏内画面与本整合稿逐字一致。分支 feat/1.5.4-ops-activity（从 dev_1.5.4 拉），合并在 1.5.4 KTP 分享链接、通知优化之后；「Koin & Jatah Saya」页和权益次数表 1.5.0 已上线，直接复用。需求见 PRD（FR-193，§3.3 / §3.5 / §3.7 / §6，文案附录 A.1）。
  1. 通知类型：新增 ACTIVITY_REWARD（到账）、ACTIVITY_RANK_WON（获奖），两类都加进 notification_center_page.dart 的后端文案条目集合（读后端存的标题 / 正文，不在 App 拼）；_iconStyle 都用 (Icons.campaign_rounded, AppColors.mint, AppColors.violet100)；正文 2 行 + 现有「Lihat semua」展开（A4）
  2. 点开：到账 → 奖励含免费次数进 /me/pawcoin（「Koin & Jatah Saya」）；没有免费次数、含头像框进 /me/growth?frame={token}（G1）；只剩优惠券进「Kupon Saya」；获奖 → 帖子详情，并加进 _postGone（帖子已删留在通知中心 + toast）
  3. 推送：获奖推送分类 PROMO；1.5.2 起 kPushDirectTypes 已删除，推送点开和通知中心点开统一走 resolveNotificationTarget：在那里登记 ACTIVITY_RANK_WON → 帖子、ACTIVITY_REWARD → 上面的落点，不要把 kPushDirectTypes 加回来。获奖推送不计 1.5.4 每天 8 条上限和运营每天 2 条，但遵守 00:00–07:00 免打扰（PRD §3.5）
  4. 免费礼物三档：「JATAH GRATIS」区和次数记录按档显示（B1，卡名 entitlementFamilyGift 改带价格参数）；送礼包装页按礼物单价匹配档、按档扣次数（B2，去掉写死的 1000）；后端新增 GIFT_5K / GIFT_10K，扣次数按具体档扣（PRD §6）。活动不发 PawCoin，PawCoin 记录不改
  5. 活动发的头像框（PRD §3.10）：头像框接口给每款带「活动专属」「永久」标记；等级页卡片和抽屉按 G1 / G2 显示「Khusus event」「Permanen」、不出「Beli lagi」；活动专属款只在拥有有效的一份时出现；快到期提醒按发送时的专属标记选新正文、跳转不带 sheet=rebuy（G3 / G4）；永久框不发到期提醒
  6. 付款抽屉（PRD §3.11）：PayChannelPicker 复用 1.5.2 头像框已加的可选参数 coinPrice（PawCoin 卡单独价）/ coinConfirmLabel（选 PawCoin 时按钮「Bayar {n} PawCoin」）：传了 → PawCoin 卡显示它、余额判断和扣币按它；本版再加右上角「推荐」小圆标（紫底 mint 24 圆、白色 thumb_up 14，距卡片上、右各 10；读屏文字 payRecommended「Disarankan」/「Recommended」）；直接付卡和 QRIS 金额仍用 price；主按钮金额跟所选方式；带数量时两种方式各按自己的单价 × 数量。不传时（AI 问诊、礼物）像素和行为都不变。调用方：头像框、KTP 高清、护照快照、登机牌、性格测试解锁 / 配型 / 补差价、超值礼包、宠物名额租用 / 续租
  7. 文案：App 端新增「Khusus event」「Permanen」两条 .arb，entitlementFamilyGift 改带价格参数（见下表）；到账 / 获奖文案进后端 messages_*.properties，按 PRD 附录 A.1，不要自己翻译
  8. 测试与验收：通知行图标 / 文案 / 跳转的 widget 测试；推送直达测试；免费次数按档显示与扣减测试；等级页活动专属 / 永久框显示与到期提醒文案测试；验收逐屏对照拆页截图

核对说明

  2. 对照代码（origin/dev_1.5.2）：字体内嵌 Poppins；通知行照 notification_center_page.dart（_NotificationTile / _iconStyle / _relativeTime），并按 1.5.4 通知优化去掉按天分组、未读图标块白底细边；免费次数卡照 _FamilyCard；送礼包装页照超值礼包稿 E4；等级页与抽屉照 1.5.2 头像框稿 C2 / C4（样式按 .s-lv / .s-vp 作用域抽进本稿）；到期提醒照 1.5.2 E1 / E2。
