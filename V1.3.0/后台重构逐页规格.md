**三语约束：** 本文所有页面的界面文案均须 中文/EN/ID 三语（走 message key，禁止写死；三语文案表随各批 UI 稿交付）。

**产出方式：** 按新导航组分批产出、分批过审。**第一批 = 待办中心组（模板 A）**，兼作"标准细度"样例。

**批次状态：** 第一批（待办中心 ×7）✅ 已过审（细度即标准；A3 号随 reports 页删除留空）｜ 第二批（内容组 ×8）✅ 已过审（E1 旧批量入口直接删除） ｜ 第三批（用户 ×3 + 订单与资金 ×7）✅ 已产出待审 ｜ 第四批（商城 ×7 + 兽医问诊 ×5 + 配置安全 ×4 + 概览）✅ 已过审（2026-09-01，含 G0 全局框架）——**全部批次过审完毕，本文档定稿**

## 模板 A 通用规格（处置工作台，本组共用；各页只写内容与差异）

**布局：** 双栏。左栏固定 360px = 队列列表；右栏自适应（≥720px）= 选中项详情 + 处置操作区。顶部两条：页签行（子队列切换，各带计数）+ 筛选行。窄屏（<1024px）降级为列表/详情两屏切换。

**左栏队列行（行高 ~56px，两行式）：** 第一行 = 主标识（对象名/单号，最长 18 字截断）+ 右对齐状态色点；第二行 = 摘要（单行截断）+ 右对齐相对时间。选中行左侧 3px 主题色竖条 + 浅底高亮。**分页统一每页 20 行**（沿用现有 PAGE_SIZE=20），滚动到底加载下一页。

**处置动线（核心交互）：** 右栏操作提交走 **htmx 局部更新**（左栏该行 + 右栏刷新，不整页跳转——模板 A 内现状的 PRG 整页刷新退役，后端端点与参数不变）；处置成功 → 右下角短 toast（2s）+ **自动选中队列下一条**；键盘 ↑/↓ 切换条目。失败在操作区行内报错（沿用 err 样式），不弹整页。

**状态色点语义（全组统一）：** 🔵 待处理 · 🟡 处理中/等待外部（寄回中、待联系等）· 🔴 超时/高优 · ⚪ 终态（已处理/已驳回/已完结）。终态行只在「已处理」页签出现。

**通用件：** 各页签计数 = 该页签当前状态行数，与左侧导航角标同源、处置后即时刷新；空态 = 插画 + 「队列已清空 🎉」；**登录者无该页任一查看权限 → 待办中心组内不渲染该菜单项**；有查看权无处置权 → 右栏操作区按钮禁用并注明所缺权限名；高危操作走 `data-confirm` 二次确认（确认文案须复述对象与后果）；全部写操作照旧落审计。

# 第二批 · 内容组（模板 B / E）

## 模板 B 通用规格（管理列表，本组 B 类页共用）

**布局（上→下）：** ① 筛选栏（沿用现状 data-autosubmit 即选即查）② **摘要条**——本列表 3~5 个关键数字（各页指标见各节），随筛选联动 ③ 数据表格（行高 ~48px，状态列用色点+文字徽标，每页 20 行）④ 行点击 → **右侧滑出详情抽屉**（宽 480px，内容 + 操作都在抽屉内完成，htmx 局部提交不整页跳转）。既有独立浅详情页并入抽屉后**直接删除**（同退役原则）。

## 模板 E 通用规格（多步工作流）
