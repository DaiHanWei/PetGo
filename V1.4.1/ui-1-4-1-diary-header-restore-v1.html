V1.4.1 · Diary 页头修复（5 处）

2026-10-29 · bug 修复：①–③ 是 V1.4.0 L2 还原度提交 988c25e5（2026-10-19）改坏的，④–⑤ 是多宠物切换器的位置问题。下方 D1 = 现在，D2 = 修复后（按此实现）

为什么会变

  • ①–③：V1.4.0 送礼 / 多宠物 / 推送三份设计稿的背景里画到了 Diary 页头，但画的是简化示意（.ent2 无图标文字卡、.vtog 左对齐小胶囊、.msb 描边进度条），这块不在 V1.4.0 的改动范围内。研发做 L2 还原度时照着改了线上。以本稿为准，V1.4.0 稿里这块作废。
  • ④：Diary 页的 ListView 顶部写死 padding top 38，没有给系统状态栏让位。带灵动岛 / 刘海的 iPhone 状态栏约 54pt，切换器就压到了时间上（产品实机截图确认）。
  • ⑤：切换器下面 SizedBox(height: 10) + 标题行被右侧 38 高按钮撑高，切换器名字到「Diary {name}」之间视觉上空了约 26pt；而宠物名在切换器高亮和宠物卡里已经各出现一次，标题行本身多余。产品定：作者态去掉标题行，按钮移到切换器那一行。
